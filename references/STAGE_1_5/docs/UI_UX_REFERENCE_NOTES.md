# CN TRIAL UI/UX Concept Board — Usage Notes

File: `references/UI_UX/CN_TRIAL_UI_UX_CONCEPT_BOARD.png`

Use this image as a **visual/layout reference only** for:
- dark cinematic industrial visual language;
- main menu hierarchy;
- private room lobby and invitation code;
- 30 numbered contestant slots;
- character selection panel layout;
- Green Light gameplay HUD;
- Red Light / detection warning;
- results and next-stage panel.

The concept image is not the final implementation, and some text / counts are illustrative. Claude must read actual game state, existing networking contracts and GDD rules. The generic silhouette portraits in the board are placeholders only. Replace them with the approved final 30 character models / renders from the locked character asset set. Do not treat any generated portrait or character shown in the UI concept board as a new contestant design.
