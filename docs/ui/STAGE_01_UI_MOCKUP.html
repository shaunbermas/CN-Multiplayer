Night yard under inspection

Dark steel panels with one notched corner, porcelain type set in Barlow Condensed, and signal colours used only for what they mean. The signature is the lens, the camera aperture from The Watcher's single eye: it is the signal indicator, the brand mark and the countdown dial. Every signal also shows a word, so colour is never the only cue.
